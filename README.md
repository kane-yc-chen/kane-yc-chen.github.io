# kane-yc-chen.github.io

陳佑丞 Yu-Cheng (Kane) Chen 的個人學術網站（目前僅供臺大國發所 115-1「東亞比較立法政治專題」課程參考使用）。

- 網站：`index.html`（中英雙語，單一檔案）
- CV：`cv/CV_YuChengChen_en.pdf`、`cv/CV_YuChengChen_zh.pdf`
- CV 原始檔：`_cv_src/build_cv.py`（以 Python + Playwright 產生兩份 PDF：`python3 _cv_src/build_cv.py <輸出資料夾>`，需安裝 Latin Modern 與 Noto Serif CJK TC 字型）
- 搜尋引擎：`index.html` 設定 `noindex`，`robots.txt` 禁止抓取 `cv/`
